## Project Overview

This project demonstrates how network traffic can be monitored and controlled between Azure Virtual Machines.

Using **Wireshark** and **Network Security Groups (NSGs)**, I examined different types of network traffic and observed how changes to network security rules can affect communication between virtual machines.

The lab also provides hands-on experience with common network protocols and basic traffic analysis.

## Technologies and Tools

The following tools and technologies were used during the lab:

* **Microsoft Azure** - Virtual machine hosting and networking
* **Remote Desktop** - Connecting to the Windows virtual machine
* **Command-Line Tools** - Generating and testing network traffic
* **Wireshark** - Capturing and examining network packets
* **Network Security Groups (NSGs)** - Controlling inbound and outbound traffic
* **SSH** - Remote administration and secure communication

* **HTTP/HTTPS** - Web traffic

# Lab Objectives

The main objectives of this lab were to:

1. Create and work with Azure Virtual Machines.
2. Capture network traffic using Wireshark.
3. Identify different network protocols within captured traffic.
4. Modify Network Security Group rules.
5. Observe how security rules affect network communication.

---

# High-Level Process

The lab was completed using the following general workflow:

### Step 1 - Prepare the Virtual Machines

Set up the Windows and Ubuntu virtual machines in Microsoft Azure and establish remote access to the systems.

### Step 2 - Capture Network Traffic

Use Wireshark to monitor communication between the virtual machines and identify packets generated by different network activities.

### Step 3 - Modify Network Security Rules

Use the Azure Network Security Group to allow or restrict specific types of traffic.

### Step 4 - Compare the Results

Test the connection again after changing the security rules and use Wireshark to observe the difference in network behavior.

# Key Takeaways

This lab provided practical experience with both **network monitoring** and **network security**.

Some of the main concepts demonstrated were:

* Network traffic can be inspected at the packet level.
* Wireshark can be used to identify protocols and communication patterns.
* IP addresses and ports help identify where traffic is coming from and where it is going.
* Network Security Groups can control which connections are allowed.
* Changing a security rule can directly affect communication between systems.
* Packet captures can help troubleshoot connectivity and security issues.

---

# Conclusion

This Azure lab demonstrated how virtual machines communicate over a network and how that communication can be observed with Wireshark.

Combining packet analysis with Network Security Groups provides a useful way to understand both **how network traffic works** and **how access to that traffic can be controlled**.
